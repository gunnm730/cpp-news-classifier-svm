## 模块设计

### 1. core 模块（训练）

**职责**：模型训练和序列化

**文件**：
- `svm.hpp/cpp` - SVM 核心算法
- `Tfidfvectorizer.hpp/cpp` - TF-IDF 算法
- `onetoall.hpp/cpp` - 一对多分类
- `Preprocessor.hpp/cpp` - 文本预处理
- `types.hpp` - 类型定义

**特点**：
- 不参与运行时推理
- 仅用于训练阶段
- 输出序列化模型文件

### 2. my_svm 模块（推理）

**职责**：加载预训练模型，执行推理

**文件**：
- `svm.hpp/cpp` - SVM 模型加载
- `tfidf_vectorizer.hpp/cpp` - TF-IDF 模型加载
- `classifier.hpp/cpp` - 分类器封装
- `model_serializer.hpp/cpp` - 序列化工具

**特点**：
- 仅包含推理功能
- 不包含训练代码
- 通过文件加载模型

### 3. proxy 模块

**职责**：模型代理，路由分发

**文件**：
- `i_model_proxy.hpp` - 接口定义
- `svm_predictor.hpp/cpp` - SVM 预测器
- `bert_predictor.hpp/cpp` - BERT 预测器（桩）
- `proxy_manager.hpp/cpp` - 代理管理器

### 4. api 模块

**职责**：HTTP 请求处理

**文件**：
- `http_request.hpp/cpp` - 请求解析
- `http_response.hpp/cpp` - 响应构建
- `classification_controller.hpp/cpp` - 分类控制器

### 5. service 模块

**职责**：任务协调

**文件**：
- `task_coordinator.hpp/cpp` - 任务协调器

### 6. parser 模块

**职责**：文件解析

**文件**：
- `i_parser.hpp` - 解析器接口
- `txt_parser.hpp/cpp` - 文本解析
- `docx_parser.hpp/cpp` - Word 解析
- `zip_parser.hpp/cpp` - ZIP 压缩包解析
- `parser_factory.hpp/cpp` - 解析器工厂

### 7. preprocessor 模块

**职责**：文本预处理

**文件**：
- `text_preprocessor.hpp/cpp` - 文本预处理
- `tokenizer.hpp/cpp` - 分词器
- `cleaner.hpp/cpp` - 文本清洗

### 8. response 模块

**职责**：响应格式化

**文件**：
- `formatter.hpp/cpp` - JSON 格式化
- `csv_generator.hpp/cpp` - CSV 生成

### 9. network 模块

**职责**：HTTP 服务器

**文件**：
- `http_server.hpp/cpp` - HTTP 服务器封装

## 数据流

### 分类请求处理流程

```
1. HTTP 请求到达
   │
2. HttpServer 接收请求
   │
3. ClassificationController::onPostClassification()
   │
4. 参数解析 (parseRequestParams)
   │  ├─ JSON 解析
   │  ├─ 表单解析
   │  └─ 文件上传解析
   │
5. 参数验证 (validateParams)
   │
6. 创建 ClassificationTask
   │
7. TaskCoordinator::process()
   │
8. 文件解析 (ParserFactory)
   │  └─ 生成 Document
   │
9. 代理路由 (ProxyManager)
   │
10. 模型预测 (SvmPredictor)
    │  ├─ 文本预处理
    │  ├─ 分词
    │  ├─ TF-IDF 向量化
    │  └─ SVM 预测
    │
11. 返回 Result
    │
12. 响应格式化
    │  ├─ JSON 格式
    │  └─ CSV 格式
    │
13. HTTP 响应发送
```

## 关键组件

### IModelProxy 接口

```cpp
class IModelProxy {
public:
    virtual ~IModelProxy() = default;
    virtual std::string predict(const std::string& text, 
                                const std::string& model_id) = 0;
};
```

### ClassificationTask 结构

```cpp
struct ClassificationTask {
    Category category;              // 领域分类
    std::string model_id;          // 模型标识
    bool is_file_mode;             // 是否为文件模式
    FileType file_type;            // 文件类型
    std::string raw_text;          // 原始文本
    std::vector<uint8_t> raw_data; // 原始文件数据
};
```

### Result 结构

```cpp
struct Result {
    std::string label;             // 预测标签
};
```

## 模型文件格式

### 1. SVM 模型文件 (svm_model.bin)

```
┌──────────────────────────────────┐
│ Magic: "SVM " (4字节)            │
├──────────────────────────────────┤
│ Version: 1 (4字节)              │
├──────────────────────────────────┤
│ 模型数量 N (8字节)              │
├──────────────────────────────────┤
│ 模型1数据                        │
│ ├─ Magic: "SVM1"               │
│ ├─ name_ (8字节)                │
│ ├─ offset_ (8字节)              │
│ ├─ learning_rate_ (8字节)        │
│ ├─ regularization_ (8字节)       │
│ ├─ max_features_ (8字节)         │
│ ├─ 向量数量 M (8字节)            │
│ └─ M个(索引, 值)对              │
├──────────────────────────────────┤
│ 模型2数据                        │
│ ...                              │
├──────────────────────────────────┤
│ 模型N数据                        │
└──────────────────────────────────┘
```

### 2. TF-IDF 模型文件 (svm_model_tfidf.bin)

```
┌──────────────────────────────────┐
│ Magic: "TFID" (4字节)           │
├──────────────────────────────────┤
│ Version: 1 (4字节)              │
├──────────────────────────────────┤
│ 词汇表大小 V (8字节)            │
├──────────────────────────────────┤
│ 词汇表数据                       │
│ ├─ 词语1长度                     │
│ ├─ 词语1内容                     │
│ ├─ 词语1 ID                      │
│ ...                              │
├──────────────────────────────────┤
│ IDF向量大小 (8字节)             │
├──────────────────────────────────┤
│ IDF向量数据 (V×8字节)          │
├──────────────────────────────────┤
│ ID到词语映射大小 (8字节)        │
├──────────────────────────────────┤
│ ID到词语映射数据                 │
└──────────────────────────────────┘
```
